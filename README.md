Currently only 5 colony items total. They will drop from "Claim Colony Items: xxx" bounty in MagicLib Bounty Board. 3 of those will be unlocked after player level 8, 1 more at player level 15, then 1 more after the player successfully completed the level 15 bounty.

Note: I didn't add these items to normal loot tables to not dilute it, so they shouldn't drop anywhere else unless another mod did it.

Should be compatible with any mod, since this mod just add some items.
